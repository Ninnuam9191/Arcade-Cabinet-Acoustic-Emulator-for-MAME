# CAVE CV1000 / "Cave SH-3" hardware (Mushihimesama, Espgaluda II, Ibara,
# Pink Sweets, Mushihimesama Futari, Muchi Muchi Pork!, Deathsmiles,
# DoDonPachi DaiFukkatsu - 2004-2012). Covers the
# original Deathsmiles (CV1000B) - NOT Deathsmiles II, which ran on
# different "CAVE PC" hardware.

# later generation than the 1st-gen boards' YMZ280B/OKI PCM setup).

# JAMMA wiring, no deluxe cabinet program. See HARDWARE-NOTES.md.
# NOTE: DoDonPachi DaiOuJou Tamashii is PGM2, not CV1000. Do not use this
# preset for that title. Ketsui and the original Espgaluda are also not CV1000.
